# v0.3.1 → v0.3.2 手机触控补丁

这是增量补丁，不是完整项目。需要已有 DungeonGame v0.3.1。当前战斗难度、伤害、敌人速度、波次与寻路算法保持不变。

## 安装

1. 备份现有项目。如果你自行改过下面五个文件，先保存自己的修改，避免直接覆盖丢失。
2. 将补丁内以下文件复制到原 DungeonGame 中相同位置，选择替换：

| 文件 | 改动 |
| --- | --- |
| js/input.js | 双指独立归属、释放捕获、中断清理、旋转暂停、防重复绑定 |
| js/lifecycle.js | 开始/重开时聚焦画布不引发滚动 |
| css/style.css | 横屏摇杆位于画布两侧、安全区、44px 按钮、混合输入设备支持 |
| index.html | v0.3.2 版本标记和横屏提示 |
| serve.py | 增加可选 --lan 参数，方便手机局域网测试 |

3. 可选：把 tests/touch.test.js 放到原 tests 文件夹。它只用于开发测试。
4. 原服务终端按 Ctrl+C 停止，重新启动服务（这次修改了 serve.py，所以需要重启）。
5. 刷新游戏，右上角应显示 v0.3.2 · 触屏优化。后续只改 JS/CSS 时无需重启服务。

没有包含的模块不用修改。不要拿补丁目录当作完整游戏运行。

## 手机实际访问：Windows 电脑与手机连接同一个 Wi-Fi

在 DungeonGame 的 VS Code 终端运行：

```powershell
python serve.py --lan
```

如果你的电脑使用 py 命令，就运行 `py serve.py --lan`。

另外打开一个终端，运行：

```powershell
ipconfig
```

找到当前连接网络的 Wi-Fi 或以太网适配器的 IPv4 地址。例如它是 `192.168.1.25`，就在手机 Safari/Chrome 输入：

```text
http://192.168.1.25:8000/index.html
```

示例 IP 必须换成电脑自己的 IPv4 地址。手机上的 127.0.0.1 指手机自己，不能用来连接电脑。

如果 Windows 弹出 Python 防火墙询问，在你信任的家庭/私人网络上允许访问即可；不需要关闭整个防火墙。校园/访客 Wi-Fi 可能隔离设备；这种网络下局域网访问可能失败。

`--lan` 会允许同一网络上的设备读取这个游戏目录，测试时只在信任的网络上启用，测试后按 Ctrl+C 停止。未加 --lan 时仍然仅供电脑自己访问。

## 推荐真机验收：横屏一轮、竖屏一轮

1. 点开始。左拇指拖动左摇杆，人物应移动。
2. 不松开左手，用右拇指拖动右摇杆，应能边走边瞄准射击。
3. 保持右手、松开左手：人物停下，射击继续。
4. 保持左手、松开右手：人物继续移动，停止产生新子弹。
5. 手指滑出摇杆底座仍能操作；松手后旋钮回中。
6. 两指按住时点击暂停，继续后应保持静止，重新按摇杆才有动作。
7. 按住摇杆时旋转屏幕，应暂停并释放触点；继续后可重新操作。
8. 切到其他应用再回来，应暂停，不应自动移动或射击。
9. 横屏下摇杆应在战斗区域两侧，按钮和摇杆无需滚动寻找；竖屏下摇杆位于画布下方。浏览器工具栏和系统手势可能影响实际可用高度，请以真机为准。
10. 完成一分钟试炼或死亡后重开，血量和计时应恢复，旧触点不应继续生效。

竖屏可操作，但战场较小，推荐横屏试玩。刷新会重开整局。长按摇杆不应选中文本或弹出菜单；系统屏幕边缘手势仍由操作系统控制。

## 技术依据

- Pointer capture: https://developer.mozilla.org/en-US/docs/Web/API/Element/setPointerCapture
- Pointer cancellation: https://developer.mozilla.org/en-US/docs/Web/API/Element/pointercancel_event
- Mixed input detection: https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/any-pointer

采用任何粗指针设备检测（any-pointer），因此平板连接鼠标后也不只依赖主指针类型。系统取消触摸或捕获丢失时显式清空输入，防止残留移动与射击。
