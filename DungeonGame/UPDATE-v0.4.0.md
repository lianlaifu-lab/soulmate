# v0.4.0 武器系统补丁（适用于 v0.3.3）

这是增量补丁，需要原完整游戏，不能单独运行。
你已将项目移到仓库根目录：以现有 index.html 所在文件夹为根目录，不要新建 DungeonGame 嵌套层。

## 安装
先备份当前版本，再按相同路径逐个替换文件。不要删除 js 或 css 文件夹。

新增：js/weapons.js。
替换：index.html、css/style.css、js/game.js、js/lifecycle.js、js/input.js、js/renderer.js、js/ui.js。
如果要运行自动测试，同时替换 tests/game.test.js、tests/touch.test.js。
其他文件（包括 main.js、immersive.js、combat.js、state.js、serve.py）保留。
本地保存后刷新即可，不需要重启 Python。线上需 Commit、Push，等 Pages 部署成功后刷新。

## 玩法
开局持有手枪。出生点左边是霰弹枪，右边是连发枪；靠近至 32 世界单位范围会自动拾取、装备并放入背包。
右下角按钮点击循环切换已拾取武器；Q 键同样循环切换。数字键 1/2/3 对应手枪/霰弹枪/连发枪，尚未拾取的不能切换。
鼠标左键按住射击；手机拖动右摇杆瞄准并射击。切枪按钮与右摇杆错开，支持另一手继续移动。
连发枪每次扳机触发三连发；触发后即使松开也会完成这一组三发。切换武器会取消剩余连发，保留射击冷却。
本版弹药无限，无换弹系统。死亡重开恢复手枪和两个拾取点。

## 参数（统一在 js/weapons.js 的 WEAPONS）
手枪：12 伤害 / 0.28 秒间隔 / 精准单发 / 最长射程 728。
霰弹枪：每颗 5 伤害 × 6 颗 / 0.72 秒间隔 / 扇形散射 / 最长射程 230，适合近距离。
连发枪：每发 6 伤害 × 3 连发 / 组间触发间隔 0.46 秒 / 组内间隔 0.085 秒 / 最长射程 690。
射程以 speed × maxLife 计算，实际受墙壁和命中限制。数值是原型设计，后续可按试玩调整。
WEAPONS 也统一保存武器颜色和简图矩形；地面、玩家手持与切换按钮复用同一份简图数据。

## 界面
右上角：爱心 + 动态血条 + 当前/最大生命值，与暂停按钮并列。
血量 >60% 为绿色，30%～60% 为黄色，≤30% 为红色。重开恢复 100/100。
右下角：当前武器简图、名称、背包序号；只有一把时点击会提示先拾取。
