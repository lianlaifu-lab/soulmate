# v0.5.0 屏幕、触控、金币与怪物更新

基于已经安装的 v0.4.0 武器版本。不是完整游戏，必须保留旧项目其他文件。

## 安装
1. 备份现有项目。
2. 解压补丁，把 index.html 放到你原 index.html 所在目录。
3. css/style.css 覆盖同名文件。
4. js 中替换 input.js、renderer.js、combat.js、game.js、lifecycle.js、ui.js。
5. js 中新增 viewport.js、coins.js、monsters.js。
6. tests 两个同名文件可覆盖，用于测试，不影响游戏运行。
不要删除 js 或 css 文件夹；不要把整个补丁嵌套到新子文件夹。
7. 仍用 python serve.py 启动；打开 http://127.0.0.1:8000/index.html，Ctrl+F5 刷新。
8. GitHub 更新：保存全部文件 → 暂存 → Commit → Push/同步更改 → 等待 Actions 成功 → 手机重新载入。

## 改动
- 画布填满当前可用浏览器视口，等比放大，不拉伸人物。镜头跟随玩家并限制在房间边界。宽屏/竖屏视野不同，不保证同时看见整个房间；横屏更适合战斗。网页无法靠 CSS 隐藏 Safari 地址栏，仍可从主屏幕 Web App 入口游玩。
- 左半屏任意非按钮位置按下并拖动移动，右半屏按下并拖动瞄准射击。初次按下不移动/不开火，拖动越过死区才生效。摇杆跟随手指，抬手消失；跨中线不会改变原控制归属。
- 右下角切枪在按下时执行，保留移动与射击触点。可以左手持续移动、右手点切枪；也可第三指切枪。只能切换已拾取武器，开局先靠近地上两把武器。
- 每次击杀掉落 2–6 枚金币，散落半径最多 42 世界单位。玩家 110 世界单位内且无墙阻隔时吸附，进入 16 单位范围拾取。血条下方显示金币图标和数量。金币为当局计数，重新开始清零，尚未加入商店或永久存档。
- 原创 Canvas 像素怪物：近战绿史莱姆、远程紫袍巫师、冲锋橙甲角兽。保留预警、血条和受击闪白，不依赖网络素材。

## 调整数值
js/coins.js 顶部 COIN_CONFIG：min/max 数量、scatter 散落半径、magnet 吸附范围、speed 吸附速度、pickup 拾取范围。以上均为世界单位，会随画面等比缩放。
js/monsters.js 管理怪物造型，js/viewport.js 管理镜头。
