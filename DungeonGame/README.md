# 微光地牢 v0.5.1

原生 ES Modules + Canvas 2D，单房间生存射击游戏。基于用户提供的 DungeonGame5.0 原项目增量整理，未更换架构。

## 更新安装（先阅读）

本包是完整可运行项目，也可按路径覆盖原项目。先备份原文件夹。打开解压后的 DungeonGame-v0.5.1 文件夹，把里面的文件复制到**原 index.html 所在目录**，不要把 DungeonGame-v0.5.1 整个文件夹嵌套进去后还继续打开旧网址。

运行所需替换：index.html、css/style.css，以及 js 文件夹里的全部 21 个同名文件。合并文件夹、覆盖同名文件即可，不需要删除原目录。每一条 JS import 都必须指向同一发布版本，因此本次不要只挑 input.js 或 renderer.js 替换。

同时更新 package.json、tests/、README.md、CHANGELOG.md，加入 UPDATE-v0.5.1.md 和 DEVELOPMENT_LOG.md。serve.py 原样随包提供，无需修改。旧版 UPDATE 文档仅作历史参考。

## 打开与确认版本

本地运行 `python serve.py`，访问：

```
http://127.0.0.1:8000/index.html?v=0.5.1
```

不要双击 HTML 以 file:// 方式运行。菜单中应该看到 **v0.5.1 · 已加载**。如果看不到，当前加载的仍不是本次 HTML；检查打开路径/部署目录。显示“加载失败”则检查 css/js 是否完整、服务器是否正确提供模块。HTML 的页面查询参数用于重新请求新页面；所有运行 JS 依赖和 CSS 也统一带版本参数。

上传 GitHub Pages 时，需要把改动提交、推送到实际发布分支和目录，等待部署成功后，再访问原游戏地址并在 URL 加上 `?v=0.5.1`（有查询参数时加 `&v=0.5.1`）。仅替换本地文件不会自动更新线上网站。本轮没有代为推送或发布。

## 五项效果

1. 全视口画布，等比跟随相机；不拉伸人物，屏幕比例不同时显示部分房间。画布填满网页可用区域，不承诺隐藏 Safari 工具栏或系统手势区。
2. 左半屏任意非按钮区域拖动移动，右半屏拖动瞄准射击。按下显示摇杆、拖动底座跟随、松手隐藏。轻触不自动开火，跨中线保持原触点归属。
3. 左手持续移动，右手点击右下角武器按钮切换；支持移动和射击时第三指点击。先走近地面的霰弹枪/连发枪拾取，开局只有手枪时无法切到未拥有武器。正在瞄准的手指要先抬起再点切枪，拖动已有瞄准触点到按钮上不会被当作新点击。
4. 击杀掉落 2–6 枚金币，42 世界单位散落范围；玩家 110 单位内且无墙阻隔时吸附，16 单位内拾取；血条下方金币图标+计数。重开清零，暂未加入商店和永久存档。
5. 原创程序化像素怪物：近战绿史莱姆、远程紫袍独眼巫师、冲锋橙甲角兽。保留各自预警、血条、受击闪白，不依赖外部图片。

桌面：WASD/方向键移动，鼠标左键射击，Q 循环切枪，1/2/3 选择已拾取武器，Esc 暂停。

## 验证

无需 npm install。项目根目录运行 `npm test`，或 `node --test tests/*.test.js`。
本轮 33 项测试通过，覆盖战斗、碰撞、武器、金币、触点、中断、入口、加载错误和版本一致性。25 个 JS（含测试）语法通过；带版本参数的 23 个 HTTP 资源检查通过。
测试是逻辑/DOM 替身/事件模拟，不等于真实浏览器视觉验收。当前环境 Chromium 无法启动；iPhone Safari、iPad、Android、实际帧率未验证。

手机验收：查看版本 → 横屏开始 → 两侧空白处起手 → 同时移动射击 → 左手保持移动、右手抬起点切枪 → 击杀拾币 → 暂停重开 → 旋转/切后台再恢复。

serve.py 只监听本机、支持 --port，不支持 --lan。手机不能访问电脑的 127.0.0.1；手机可使用已部署的网址。
